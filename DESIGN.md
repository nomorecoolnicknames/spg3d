# СУПЕР ПИЗДАНУТЫЕ ГОНКИ 3Д — v2 (полный ремейк)

Одностраничный контракт для всех, кто пишет код в этом репозитории.
Старая версия лежит в `../app` и `../shitrace-deploy` — только как справка, ничего оттуда не копируем «как есть».

## Цель
Аркадная уличная гонка в духе NFS Underground / Burnout с тремя трассами, карьерой из трёх соперников
и финальным боссом-мехом. Игра должна **играться** (физика, ИИ, отклик), **выглядеть** цельно
(один арт-дирекшн, без эмодзи и случайных градиентов), **звучать** (синтезированный движок, шины,
удары, UI, босс) и собираться в **web + Android**.

Тема сохраняется: музыка madk1d / Тёмный Принц (remixxx by dj dubstep 2012), соперники sqwore /
glwzbll / Тёмный Принц, финальный босс — МЭДКИД (эмблема: бультерьер в тёмных очках,
`src/assets/madk1d_face_big.jpg`). Winamp-плеер остаётся как фишка, но аккуратно встроенный.

Вырезано из старой версии (слоп): падающие смайлики-шары, наклейки на машинах, пиксельные очки,
годзилла, фри-роам, погоня, «обложки» из скриншотов на домах, Deadpool-фанко, эмодзи в UI.

## Стек
Vite 7 + React 19 + TypeScript strict + three 0.185. Без Tailwind — свой CSS c токенами (`src/ui/theme.css`).
Шрифты локально через `@fontsource` (Russo One — заголовки/цифры, Inter — текст, JetBrains Mono — таймеры).
Аудио — Web Audio, всё синтезируется (кроме mp3-музыки). Модели машин — GLB из `src/assets/cars/`
(оптимизированные meshopt+webp копии `cars-src/`, см. `scripts/optimize-glb.mjs`).

## Экраны (`ScreenId`)
`boot` → `menu` → `career` | `quick` | `garage` | `records` | `settings`; `story` (диалог до/после);
`race` (HUD поверх сцены); `boss` (HUD босса); `results`; `pause` — оверлей внутри race/boss.

## Гоночный цикл
1. Обратный отсчёт 3-2-1-GO (музыка приглушена).
2. Фиксированный шаг физики 120 Гц, рендер по rAF, интерполяции не требуется (шаг мал).
3. Чекпоинты: трасса делится на 8 секторов, круг засчитывается только при прохождении всех по порядку.
4. Позиции — по прогрессу (круг × N + индекс сэмпла + доля).
5. Финиш игрока → 2 с «доезд», затем результаты (ИИ, не доехавшие, получают расчётное время).
6. Награды: место, дрифт-очки, чистый круг; рекорды по лучшему кругу с инициалами.

## Физика (CarPhysics)
Велосипедная модель на плоскости трассы, положение по высоте берётся из сэмпла трассы.
Двигатель: кривая момента × передача (6 ступеней, автомат) × главная пара / радиус колеса.
Шины: боковая сила = −C·slip, насыщение по μ·нагрузке; ручник режет заднее сцепление → дрифт;
контр-руление работает естественно. Стены — отражение с потерей скорости и искрами.
Единицы: метры, секунды, м/с; в HUD км/ч.

## ИИ
Едет по предрасчитанной гоночной линии (сглаженное смещение к внутреннему радиусу), целевая скорость
из кривизны с запасом торможения (lookahead), объезд впереди идущих, лёгкая резинка (±8 %) по
сложности. Использует ту же CarPhysics — только даёт inputs.

## Босс
Арена — ночная набережная Неон-Сити. Игрок пешком (Xbot, красно-чёрный костюм, анимации idle/run из GLB,
базука в правой руке). Мех МЭДКИД: ~14 м, процедурный, но «дизайнерский» — угловатая голова-визор
(силуэт бультерьера в очках), шляпа-федора, сигара с дымом, золотая цепь, панели с эмиссивными швами,
ракетные блоки на плечах, светящееся ядро на груди (уязвимая точка ×3 после залпа).
Фазы: 1) ракетные залпы + шаги; 2) миньоны + телеграфируемый лазер; 3) ярость: удар в землю с
ударной волной, ускорение. Смерть игрока — рестарт фазы. Победа — многоступенчатый взрыв, разблокировка всех машин.

## QA-хуки (`window.__spg`)
```ts
interface SpgDebug {
  ready: boolean;                 // ассеты загружены, экран menu показан
  screen: ScreenId;
  goto(screen: ScreenId, params?: Record<string, unknown>): void; // 'race' {track, car, laps, opponents}, 'boss'
  setAutopilot(on: boolean): void; // ИИ ведёт игрока / бойца
  setTimeScale(k: number): void;   // ускорение симуляции (1..8)
  snapshot(): SpgSnapshot;         // HUD, позиции, hp босса, fps, счётчик draw calls
  errors: string[];                // console.error/unhandled
}
```
URL-параметры: `?screen=race&track=neon&car=supra&auto=1&laps=1&opp=5`, `?screen=boss&auto=1`.

## Правила качества
- Никаких эмодзи и «rounded-2xl» градиентных кнопок: токены из `theme.css`, иконки — inline SVG.
- Тексты только из `strings.ts`, русская типографика («ё», «—», неразрывные пробелы где нужно).
- Никаких фейковых процентов загрузки: прогресс = байты загруженных ассетов.
- Каждый модуль имеет `dispose()`; переключение сцен не течёт (проверяется в QA по `renderer.info`).
- Мобильная раскладка: landscape 900×420 должна быть играбельна (тач-кнопки, HUD без перекрытий).
